# u-pangg7-one-line-of-wonder-ee10fcd8

```text
In the margin of the library book on tides: returned late, still wet.
```

Run it with `MAKEFUN_OUTPUT_DIR=out python3 main.py` (defaults to `/output`); it writes `entry.txt` with no trailing newline and prints the character count to stderr.
